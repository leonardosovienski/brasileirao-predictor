## Limites do backup

GitHub preserva o código e as entregas desta pasta. Não é backup integral do computador: bancos privados, credenciais, modelos locais, ambientes e backups pessoais não são publicados. Scripts históricos contêm caminhos do ambiente original e exigem adaptação/revisão antes de reexecução. Não executar scripts de instalação ou admissão apenas para ler as evidências.

Este checkpoint não faz merge em main, não instala uma nova release e não certifica vantagem preditiva ou ausência geral de bugs. Trabalho local preexistente permanece preservado nos projetos originais.
