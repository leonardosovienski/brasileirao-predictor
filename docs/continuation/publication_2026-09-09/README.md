## Limite da publicação

Este repositório é público. Dados brutos de fornecedores, payloads de odds,
corpos de páginas de terceiros, bancos, configurações privadas, credenciais,
coortes protegidas, ambientes e backups binários permanecem locais. A regra
de não redistribuir esses dados está registrada no [mapa de dados](../../DATA_MAP.md)
e no [gitignore](../../../.gitignore).

Seus caminhos, cobertura, hashes e recibos pertinentes permanecem rastreáveis.
Um clone do GitHub recupera o código e a documentação publicados, mas não
substitui o backup dos dados em `C:/BRASILEIRAO`. Não houve liberação de capital,
avaliação de coortes ou alteração da captura agendada por esta publicação.
